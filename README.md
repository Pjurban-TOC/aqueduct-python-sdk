# aqueduct-sdk
Aqueduct is an enterprise-grade AI gateway platform providing secure, multi-tenant
access to large language models with built-in DLP, safety guardrails, RAG integration,
comprehensive audit logging, and compliance controls (SOC 2, HIPAA, FedRAMP).

## Authentication

All authenticated endpoints require a Bearer JWT token or an API key via the
`X-API-Key` header. JWT tokens encode tenant context, roles, and permissions.
API keys are tenant-scoped virtual keys with configurable model access and rate limits.

Public key verification is available via the JWKS endpoint at
`/.well-known/jwks.json` (see Authentication section).

**Scope semantics:** Each endpoint lists one or more required scopes. Access is
granted if the caller holds **any** of the listed scopes (OR logic). For example,
an endpoint requiring `system:admin` or `tenant:admin` is accessible to callers
with either scope.

## Multi-Tenancy

Every request is scoped to a tenant. The `X-Tenant-ID` header is echoed in all
responses for audit trail correlation. Cross-tenant access is strictly prohibited
and enforced at the gateway layer.

## Error Handling

All errors follow [RFC 7807 Problem Details](https://www.rfc-editor.org/rfc/rfc7807)
with `application/problem+json` content type. Each error includes a machine-readable
`code` field (e.g., `ERR-API-001-001`) and a distributed `trace_id` for support.

## Rate Limiting

Rate limits follow the [IETF RateLimit Headers](https://datatracker.ietf.org/doc/draft-ietf-httpapi-ratelimit-headers/)
standard. AI inference endpoints additionally include token-based rate limiting headers
(`X-RateLimit-Remaining-Tokens`) following the Azure AI Gateway pattern.

## Planned Endpoints

Endpoints marked with `x-status: planned` are part of the architectural contract
but not yet implemented. They document the target API surface for AI gateway features
including inference proxying, DLP, RAG, safety guardrails, and audit log querying.

## Documentation For Authorization


Authentication schemes defined for the API:
<a id="BearerAuth"></a>
### BearerAuth

- **Type**: Bearer authentication (JWT)

<a id="ApiKeyAuth"></a>
### ApiKeyAuth

- **Type**: API key
- **API key parameter name**: X-API-Key
- **Location**: HTTP header

<a id="OAuth2"></a>
### OAuth2

- **Type**: OAuth
- **Flow**: accessCode
- **Authorization URL**: https://auth.aqueduct.ai/oauth2/authorize
- **Scopes**: 
 - **system:admin**: Full system administration access
 - **reseller:admin**: Reseller-level tenant management
 - **tenant:admin**: Tenant administration (CRUD, config, user management)
 - **tenant:read**: Read-only access to tenant data
 - **tenant:write**: Write access to tenant data
 - **user:admin**: User administration within a tenant
 - **user:read**: Read-only access to user data
 - **user:write**: Write access to user data
 - **breakpoint:admin**: Full CRUD on breakpoint configuration
 - **breakpoint:operator**: Review and action paused requests
 - **breakpoint:viewer**: Read-only access to breakpoints and queue
 - **api:read**: Read access to API resources
 - **api:write**: Write access to API resources
 - **api:admin**: Full API administration
 - **conversation:read**: Read access to conversation history
 - **conversation:write**: Create and modify conversations
 - **prompt:read**: Read access to prompt library
 - **prompt:write**: Manage prompt library entries
 - **billing:read**: Read billing and usage data
 - **billing:write**: Manage billing configuration
 - **audit:read**: Read audit logs
 - **model:invoke**: Invoke AI model inference endpoints
 - **dlp:scan**: Execute DLP scans on content
 - **dlp:manage**: Manage DLP policies and configuration
 - **rag:query**: Query knowledge bases for retrieval
 - **rag:manage**: Manage knowledge bases and documents
 - **safety:manage**: Manage safety guardrail configuration
 - **config:read**: Read configuration entries and feature flags
 - **config:write**: Create, update, delete configuration entries and flags
 - **compliance:read**: Read compliance frameworks, controls, and reports
 - **compliance:manage**: Run compliance checks and manage scheduler
 - **security:admin**: Manage HSM keys (generate, rotate, deactivate, destroy)
 - **security:encrypt**: Perform HSM encrypt/decrypt operations
 - **security:sign**: Perform HSM sign/verify operations
 - **security:wrap**: Perform HSM key wrap/unwrap operations
 - **tenant:owner**: Tenant owner operations (deletion requests, data export)
