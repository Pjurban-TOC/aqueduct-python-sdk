# HSMKeyType

Supported HSM key types. Post-quantum (PQC) types per NIST IR 8547 and CNSA 2.0: ML-KEM (FIPS 203), ML-DSA (FIPS 204), SLH-DSA (FIPS 205). 

## Enum

* `AES_MINUS_256` (value: `'AES-256'`)

* `RSA_MINUS_2048` (value: `'RSA-2048'`)

* `RSA_MINUS_3072` (value: `'RSA-3072'`)

* `RSA_MINUS_4096` (value: `'RSA-4096'`)

* `ECDSA_MINUS_P256` (value: `'ECDSA-P256'`)

* `ECDSA_MINUS_P384` (value: `'ECDSA-P384'`)

* `ED25519` (value: `'Ed25519'`)

* `ML_MINUS_KEM_MINUS_768` (value: `'ML-KEM-768'`)

* `ML_MINUS_KEM_MINUS_1024` (value: `'ML-KEM-1024'`)

* `ML_MINUS_DSA_MINUS_65` (value: `'ML-DSA-65'`)

* `ML_MINUS_DSA_MINUS_87` (value: `'ML-DSA-87'`)

* `SLH_MINUS_DSA_MINUS_SHA2_MINUS_128S` (value: `'SLH-DSA-SHA2-128s'`)

* `SLH_MINUS_DSA_MINUS_SHA2_MINUS_256S` (value: `'SLH-DSA-SHA2-256s'`)
